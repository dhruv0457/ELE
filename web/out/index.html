What Can ELE Do?

From coding to automation, ELE Agent handles complex multi-step tasks.

Code Generation & Refactoring

Create, edit, and refactor code across your entire codebase. Run tests, lint, and deploy.

$ele"Create a FastAPI auth module"
$ele"Add tests for user service"
$ele"Refactor to use dependency injection"

File & Project Management

Organize files, create project structures, batch rename, convert formats, and more.

$ele"Organize my downloads folder"
$ele"Create React project structure"
$ele"Convert all .md to .txt"

Web Automation & Research

Browse, scrape, fill forms, take screenshots, and extract data from any website.

$ele"Scrape pricing from competitor sites"
$ele"Fill out this job application"
$ele"Monitor this page for changes"

System Administration

Run commands, manage services, monitor resources, and automate DevOps tasks.

$ele"Restart nginx and check logs"
$ele"Show disk usage by folder"
$ele"Setup cron job for backups"
